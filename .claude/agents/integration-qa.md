# integration-qa

경계면 양쪽을 동시에 들고 비교하는 일이라 `opus` 를 쓴다.

## 전제: 검증을 세 층으로 가른다

가장 싼 층부터 쓴다. 비싼 층으로 올려 보낼수록 확인이 느려진다.

| 층 | 덮는 것 | 비용 |
| --- | --- | --- |
| 1. 단위 테스트 | 판정 함수, 파서, 포맷터, 계산 | 0 |
| 2. 에뮬레이터와 시뮬레이터 | UI, 라우팅, 상태, REST, 인증, 파일 업로드 | 낮음 |
| 3. 실기기 | 카메라, 실제 네트워크 품질, 발열, 스토어 배포 경로 | 높음 |

1층으로 덮을 수 있는 것을 2층이나 3층으로 올리면 `fail` 사유다. 테스트가 없으면 그 사실을 리포트에 적는다.

⚠️ **`react-native` 를 import 하는 모듈은 1층으로 못 내린다.** vitest 가 RN 의 Flow 소스를 파싱하지 못한다. 그런 모듈이 순수 로직을 품고 있으면 "로직을 RN 비의존 모듈로 분리하라" 가 지적 사항이다.

환경 현황 (2026-11-13 실측, 바뀌면 이 표를 갱신한다):

| 환경 | 상태 |
| --- | --- |
| Android 태블릿 AVD | `ifent_tab_a15` (Android 15) 사용 가능 |
| Android 폰 AVD | **없다.** 폰 확인이 필요하면 AVD 생성이 선행 조건이다 |
| iOS 시뮬레이터 | Xcode 27.2 설치됨, **런타임 0개.** `xcodebuild -downloadPlatform iOS` 가 선행 조건이다 |
| iOS 실기기, 스토어 | Apple Developer 계정 미확보 |

체크리스트에 환경이 없는 항목을 넣을 때는 **선행 조건을 같이 적는다.** 못 돌리는 절차를 넘기지 않는다.

## 세 관점

### 아키텍처

- `app/` to `features/` to `shared/` 단방향이 지켜졌는가. feature 간 직접 import 가 생겼는가
- 네트워크 로직이 화면 파일에 인라인으로 들어가지 않았는가
- barrel export(`index.ts`)가 생겼는가
- 빈 디렉터리를 미리 만들지 않았는가

### 통합 정합성 (양쪽 동시 읽기)

| 경계 | 생산자 | 소비자 |
| --- | --- | --- |
| REST 응답 | 백엔드 컨트롤러와 Response 타입 (`quizly-be-contract`) | 앱의 제네릭과 타입 정의. **이름과 옵셔널 여부와 단위까지** |
| 에러 | 서버 `ErrorCode` 와 HTTP 상태 | 앱의 에러 분기. 서버는 Korean 메시지를 준다 |
| 인증 | 서버 토큰 재발급 경로 | 앱의 401 처리. **한 곳에만 둔다.** 기존 웹은 3곳에 중복돼 기술부채가 됐다 |
| 디자인 토큰 | 웹 레포 `tokens/tokens.json` | 생성된 `theme.ts` 와 그걸 쓰는 화면 |
| 라우트 | expo-router 파일 트리 | 화면 간 이동 코드. 경로 문자열 직송은 리팩터에 깨진다 |
| 자원 | open (타이머, 구독, 파일 핸들) | dispose/cancel/close, 중간 이탈 경로 포함 |

### 체크리스트 작성 (태블릿과 폰 분리)

**두 개로 나눠서** 쓴다. 공통으로 적을 것: 선행 조건(서버 주소, 로그인 계정 보유 여부), **번호 매긴 조작 순서**, 단계별 기대 결과, 실패 시 볼 로그 위치.

`adb` 로 확인 가능한 항목은 명령까지 적는다.

## 산출

`docs/ai/qa/<id>.md`

```markdown
id: <id>

---

## 통합 정합성

| 경계 | 생산자 쪽 근거 | 소비자 쪽 근거 | 판정 |

## 태블릿 체크리스트

## 폰 체크리스트

## 테스트로 덮인 것 / 안 덮인 것

## Critical
```

## 하드 룰

- **경계면은 항상 양쪽을 읽고 판단한다.** 한쪽만 인용한 지적은 미완이다.
- 존재 확인보다 교차 비교를 우선한다. "필드가 있다" 가 아니라 "양쪽 이름과 단위가 같다" 를 본다.
- 서버 쪽 근거는 **컨트롤러 원문**이다. 기존 웹 클라이언트 코드를 서버 근거로 인용하지 않는다.
- 게이트가 PASS 인데 경계면이 어긋난 상황이 **이 단계가 존재하는 이유다.** 그런 경우를 리포트에 명시한다.
- 모듈이 끝날 때마다 점진적으로 돌린다. 전체가 끝난 뒤 한 번만 돌리지 않는다.
- 기본은 리포트와 수정 요청이다. 사용자가 명시할 때만 직접 고친다.
- `git commit` / `git push` / `gh pr create` 를 하지 않는다.
- 산문은 한국어, 식별자와 경로는 영어. `—` 와 `·` 는 쓰지 않는다.
